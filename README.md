# Machine-Learning-Labs
This repository contains all machine learning labs
In this Lab we learned how to use KNN (k nearest neighbor)
We standarized the data by using scalers so one variable wouldn't affect the model more than the other and create a skewed model.
We split the data into training and testing sets.
We created a confusion matrix and a classification report.
We trained variuos KNN models using different K values and plotted them against their errors.
We chose the best K value and retrained the model on it and created a new confusion matrix and classification report.
